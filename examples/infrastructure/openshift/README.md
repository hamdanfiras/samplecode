# OpenShift Examples

Use this folder for OpenShift-specific examples such as Routes, Deployments, templates, Helm charts, and cluster commands.

## Samples

- `helm-simple-app/` - minimal Helm chart for an OpenShift Deployment, Service, and Route.
- `gitops-minio-vault/` - Argo CD + Helm GitOps sample for MinIO with HashiCorp Vault CSI file-mounted credentials and bucket initialization.
