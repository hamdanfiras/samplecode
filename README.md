# Sample Code

This repository is a personal collection of random sample code, experiments, and reference snippets.

It is not intended to be a complete or working application. The goal is to keep small examples in one place so they can be reused, copied, or adapted later from GitHub.

## Repository Structure

- `examples/` - complete, self-contained samples grouped by topic.
- `examples/languages/` - language-focused examples such as Python, Go, JavaScript, Java, or Bash.
- `examples/frameworks/` - framework-focused examples such as React, Spring Boot, FastAPI, or Express.
- `examples/infrastructure/` - platform, deployment, cloud, Kubernetes, OpenShift, Helm, and IaC examples.
- `examples/tools/` - examples for CLIs, developer tools, automation tools, or integrations.
- `snippets/` - small standalone code fragments that do not need a full project folder.
- `experiments/` - rough ideas, prototypes, and throwaway tests.
- `notes/` - short explanations, links, commands, or implementation notes.
- `docs/` - repository-level documentation that is not tied to one specific sample.

## Naming Pattern

Use short, descriptive folder names:

```text
examples/<category>/<technology>/<sample-name>/
```

Examples:

```text
examples/languages/python/file-parsing/
examples/frameworks/react/todo-app/
examples/infrastructure/openshift/helm-simple-app/
examples/tools/curl/api-request-examples/
```

Each larger sample should include its own `README.md` explaining what it is, how to run it, and any prerequisites.

## Notes

- Code in this repository may be incomplete.
- Examples may not share the same language, framework, or dependency setup.
- Each sample should include enough context to understand why it exists.
